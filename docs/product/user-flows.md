# 页面与业务流程

## 小程序页面

### 首页

- 展示社区名称、简介和主视觉图。
- 展示公告/通知入口。
- 展示服务分类入口和商城入口。
- 展示精选商品或社区推荐内容。

### 服务展示

- 服务列表：名称、简介、图片、服务状态。
- 服务详情：服务说明、适用范围、联系方式或预约方式。
- 首期不包含线上服务预约和设备控制。

### 商城

- 分类页和商品列表。
- 商品详情：主图、名称、价格、说明、配送/自提说明。
- 下单确认：商品、数量、联系人、手机号、地址、备注。
- 下单成功页：展示订单号、未支付提示和订单详情入口。

### 我的

- 用户信息/登录状态。
- 我的订单及状态筛选。
- 订单详情：商品快照、联系信息、订单状态、支付状态、创建时间。

## 下单流程（无在线支付）

1. 用户打开商品详情并选择数量。
2. 用户填写联系方式、地址和备注。
3. 小程序提交订单请求。
4. 后端校验商品是否上架、价格和数量，并创建订单及订单明细。
5. 订单状态设为“待确认”，支付状态设为“未支付”。
6. 用户看到订单号，并可在“我的订单”中查看进度。
7. 后台人员确认订单、安排履约，并更新状态；如线下收款，可单独标记收款状态。

## 后台手动录单流程

1. 管理员登录后台并打开订单管理。
2. 点击“新建订单”，录入客户信息、商品、数量、地址和备注。
3. 后端按录入时的商品价格生成订单快照，订单来源设为“后台录入”。
4. 管理员保存后可继续更新履约状态和线下收款状态。

## 建议订单状态

| 状态 | 含义 |
|---|---|
| 待确认 | 订单已提交，运营方尚未确认 |
| 待配送/待自提 | 已确认，等待履约 |
| 配送中 | 正在配送（仅配送订单适用） |
| 已完成 | 履约完成 |
| 已取消 | 订单已取消 |

支付状态独立于履约状态：`未支付`、`线下已收款`。首期不提供在线支付状态。
