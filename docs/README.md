## 当前已确认的前提

1. 产品形态参考社区服务平台，首期提供社区内容展示和商品商城展示。
2. 首期不连接饮水机或其他物联网设备。
3. 商品由运营人员在后台维护；小程序端展示商品。
4. 小程序端暂不接入在线支付，但需要产生真实订单并查看订单状态。
5. 后台需要订单列表，并支持运营人员手动录入订单。
6. 图片暂存 ECS 本地持久目录，以控制成本。
7. 部署目标为阿里云 ECS，使用 Docker。

## 待确认事项

- 小程序用户提交订单时，是否要求手机号登录/授权，以及是否允许游客下单。
- 首期订单状态和线下收款状态是否采用本文档中的建议值。
- 商品是只支持配送，还是也支持社区自提。
- 是否需要库存数量和库存扣减。
- 后台是否由单一管理员使用，还是需要多个运营账号及权限分级。
- ECS 数据库是与应用同机运行，还是采用阿里云 RDS。
